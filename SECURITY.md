# امنیت / Security

**فارسی:** [سیاست کامل امنیتی](docs/fa/security.md) · **English:** [Full security policy](docs/en/security.md)

این مخزن عمومی فقط مستندات پژوهشی و ارجاع به منابع شخص ثالث را ارائه می‌کند و سرویس عملیاتی نیست. نام کاربری و رمز، کلیدهای دسترسی، اطلاعات شخصی، جزئیات اکسپلویت، داده‌های محرمانه و اطلاعات اختراعات منتشرنشده را در Issue عمومی درج نکنید. برای گزارش حساس، ابتدا از مسیر خصوصی مورد توافق استفاده کنید؛ در صورت نبود چنین مسیر مشخصی، در Issue عمومی صرفاً درخواست معرفی کانال خصوصی بدهید و جزئیات فنی حساس را منتشر نکنید.

**English:** The public repository contains research documentation and third-party references, not an operating service. Do not post credentials, exploits, private data, confidential infrastructure details, or undisclosed inventions in public Issues. If sensitive material must be reported, request a private reporting path without publishing the details in the public issue.
