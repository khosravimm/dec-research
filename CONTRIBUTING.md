# Contributing / مشارکت

[English policy](docs/en/contributing.md) · [سیاست فارسی](docs/fa/contributing.md)

Please start with **non-confidential GitHub Issues**. The project does not yet accept code/weight/data pull requests under a specified public licence. A separate written contribution and rights agreement is required before third-party artifacts are merged.

لطفاً گفتگوهای **غیرمحرمانه** را از Issues شروع کنید. پیش از توافق حقوق مشارکت، ارسال و ادغام کد، وزن مدل یا مجموعه داده اشخاص ثالث تحت مجوز عمومی اعلام نشده است.
