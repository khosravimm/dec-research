# قرارداد بازتولیدپذیری

## مصنوعات مورد انتظار

هر آزمایش پذیرفته‌شده تا حد مجوز انتشار باید شناسه و SHA256 داده/Fixture، شناسه و منبع نسخه مدل و LoRA **بدون بازنشر وزن فاقد مجوز**، نسخه Runtime و Container، مشخصات کلی و غیرقابل‌شناسایی CPU/GPU، تنظیمات اجرا، Seed، ورودی و پاسخ مرجع، نتایج عددی خام، اسکریپت محاسبه، شکست‌ها و رده شاهد را ارائه کند.

## طرح داده

[دفتر آزمایش‌ها](../../research/experiment-register.json) شناسه و عنوان **دوزبانه**، وضعیت، پیوند منابع و سنجه دارد. [کاتالوگ پژوهشی](../../research/catalogue.json) فهرست دوزبانه ارجاع‌ها است و کتاب دارای حقوق نشر یا کد اشخاص ثالث را ذخیره نمی‌کند.

حداقل فیلدهای اجرای `RUN-ID` آینده: `experiment_id`، `run_id`، `dataset_sha256`، `runtime_revision`، `model_revision`، `adapter_revision`، `config_sha256`، `task_count`، `correct_count`، `error_count`، `latency_ms_p50`، `latency_ms_p95`، `ttft_ms`، `peak_rss_bytes`، `peak_vram_bytes`، `token_prefill`، `token_generated`، `tensor_transfer_bytes`، `evaluator`، `limitations` و `evidence_grade` است.

برای سنجه ناموجود مقدار ساختگی یا صفر درج نشود؛ `null/unknown` مناسب است. داده شبیه‌سازی‌شده باید صریحاً مشخص باشد. تکرارها و پراکندگی نتایج گزارش شود و شکست بازتولید هم یافته قابل انتشار است.

## یکپارچگی و زمان

Commitهای Git برای تاریخچه عمومی و Manifestهای تاریخ‌دار SHA256 برای کنترل محتوا استفاده می‌شوند. Git Hash و زمان Commit در ردیابی کمک می‌کنند اما گواهی مستقل و قطعیِ اولویت اختراع یا مالکیت نیستند. Traceهای خام در صورت خطر افشای Secret، داده شخصی، مکانیزم منتشرنشده یا سند دارای حقوق نشر، خصوصی باقی می‌مانند.

## اعتبار علمی

امتیاز مقاله دیگران فقط نتیجه گزارش‌شده همان مقاله است؛ تنها اجرای واقعی DEC حق ارتقا به E1/E2/E3 دارد. مقایسه کیفیت باید بودجه کل محاسبات، مجموعه اسناد، طول ورودی، قالب Prompt و وضعیت Adapter را کنترل کند. شکست‌ها، گزینه‌های رقیب جدی و متغیرهای مداخله‌گر نیز بیان شوند.
