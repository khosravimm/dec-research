# پروتکل آزمون‌های آزمایشگاهی

## پرسش پژوهش و واحد مقایسه

واحد آزمایش **پرونده** است: یک تکلیف ثابت با پاسخ مرجع، مجموعه شواهد و Rubric داوری. تکلیف‌ها، دسترسی به شواهد و حدود سخت‌افزار برای گزینه‌های مقایسه یکسان می‌مانند. هر اجرا شناسه، هش نسخه مدل و Adapter، Quantization، Prompt، نسخه داده و شرایط اندازه‌گیری خواهد داشت. پیش از تثبیت پروتکل، اجرای مقدماتی «موفقیت» تلقی نمی‌شود.

## بازوهای آزمایش (برنامه‌ریزی‌شده، E0)

| بازو | پیکربندی | متغیر اصلی |
|---|---|---|
| A0 | یک مدل کوچک، پاسخ مستقیم | حداقل هزینه |
| A1 | همان مدل + RAG اختصاصی | اثر بازیابی دانش |
| A2 | همان مدل + Prompt نقش + همان RAG | اثر تخصص Prompt |
| A3 | همان مدل + LoRA آموزش‌دیده + همان RAG | ارزش افزوده LoRA |
| A4 | متخصص واحد با Thinking ساختاریافته عمیق و ابزار | اثر استدلال |
| A5 | شورای ثابت ۲ تا ۳ متخصص با پیام ساختاریافته | اثر شورا و سربار مبنا |
| A6 | شورای L1/L2/L3 تطبیقی با پیام ساختاریافته | اثر Routing و توقف |
| A7 | همان شورا با تبادل نهفته سازگار و حافظه محدود | اثر ارتباط برداری |
| A8 | مدل مرجع بزرگ‌تر با بودجه محاسباتی اعلام‌شده | مقایسه مقیاس |
| A9 | معماری عصبی یکپارچه (آینده مشروط) | اثر مکانیزم جدید |

تا تحقق قرارداد بازنمایی سازگار، بازوی A7 و A9 قابل اجرا نیستند. **هیچ بازویی در این مخزن اجرا نشده است.**

## داده‌ها

سؤال‌های مستقل و دوزبانه شامل تحلیل رخداد شبکه و امنیت، عیب‌یابی، برنامه‌نویسی، تصمیم‌های مدیریتی، تناقض میان‌حوزه‌ای، بازیابی محتوای نامطمئن، کمبود شاهد و امتناع از پاسخ خواهند بود. هر سؤال شناسه، زبان، دشواری، پاسخ مرجع، داده بازتولیدپذیر، حق انتشار، درجه حساسیت و داور مستقل دارد. اطلاعات محرمانه سازمانی وارد داده‌های عمومی نمی‌شود.

## خروجی‌ها

اصلی: صحت واقعی و وفاداری به شواهد با داوری مستقل. فرعی: امتناع درست، کشف تناقض، سودمندی تصمیم، توکن ورودی/خروجی، TTFT سرد/گرم، تأخیر p50/p95، توکن‌برثانیه، RAM/VRAM بیشینه شامل KV و LoRA، حجم Tensor، صحت Cache و انرژی به‌ازای پاسخ پذیرفته‌شده در صورت اندازه‌گیری معتبر.

## متغیرهای مداخله‌گر و پذیرش

سخت‌افزار، Context، تنظیمات تولید، بودجه بازیابی و مجموعه آزمون ثابت می‌مانند؛ علاوه بر تأخیر خام، کیفیت در بودجه پردازشی برابر مقایسه می‌شود. تکرار کنترل‌شده، عدم‌قطعیت و بازه اطمینان، شکست‌ها و خطای Parser گزارش می‌شوند. آستانه‌های کمی پذیرش **پیش از** آموزش یا مشاهده نتیجه آزمون نهایی تثبیت خواهند شد؛ فعلاً بازند. ناسازگاری، مجوز نامشخص، ضعف فارسی، نشت یا مصرف حافظه زیاد می‌توانند علت رد باشند.
