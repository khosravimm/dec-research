# واژه‌نامه

| اصطلاح | مفهوم و مرز استفاده در DEC |
|---|---|
| DEC | نام کاری Deliberative Expert Council؛ نه نام مدل جدید اثبات‌شده یا علامت ثبت‌شده |
| هسته کوچک | مدل عصبی مولد مشترک و قابل تعویض |
| بسته متخصص | نقش منطقی شامل LoRA، کنترلر، RAG اختصاصی، سیاست بازیابی و نسخه |
| LoRA / QLoRA | تنظیم کم‌پارامتر وزن‌ها / آموزش کم‌بیت؛ نه تضمین اشتراک حافظه |
| RAG | بازیابی بیرونی برای اتکا به واقعیت؛ Embedding بازیابی وضعیت ادامه مدل نیست |
| Hidden State | فعال‌سازی داخلی مربوط به لایه و نسخه مشخص |
| KV Cache | کلید/مقدار Attention وابسته به لایه و موقعیت؛ بازاستفاده نیازمند سازگاری دقیق |
| Latent Workspace | حافظه کاری داخلی فشرده پیشنهادی؛ هنوز در DEC پیاده نشده |
| Latent-first | حذف تبدیل غیرضروری متن و توکن **در صورت منفعت اثبات‌شده** |
| شورای متخصصان | نقش‌های فعال‌شونده پویا با نقد و بازنگری مبتنی بر شواهد؛ نه اجماع اجباری |
| دفتر شواهد | شناسه ادعا، منبع، نسخه مدل، آزمون و عدم‌قطعیت ساختاریافته |
| Think / No Think | حالت وابسته به مدل و Chat Template؛ نه تسلط مستقیم بر همه محاسبات درونی |
| P1/P2/P3 | نمونه ماژولار؛ یکپارچه‌سازی اجرایی پس از سنجش؛ معماری عصبی جدید به‌صورت مشروط |
| E0/E1/E2/E3 | نظری، نمونه مصنوعی، اجرای محدود واقعی و آزمون تکرارپذیر با دامنه مشخص |
| مالکیت فکری و زنجیره حقوق | حقوق قانونی اثبات‌پذیر و منشأ اثر؛ متفاوت از صرف نام حساب GitHub |
